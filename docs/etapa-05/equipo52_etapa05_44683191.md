## 1. Aporte realizado
- Investigación e implementación de las políticas de seguridad en SQL Server Express orientadas al sistema "Guaraní Turnos Médicos".
- Creación de inicios de sesión (`LOGIN`) y usuarios de base de datos (`USER`) con privilegios diferenciados (administrador y de solo lectura).
- Creación de un procedimiento almacenado seguro y asignación de permisos específicos de ejecución (`GRANT EXECUTE`) a usuarios sin privilegios directos de modificación.
- Creación de un rol personalizado (`CREATE ROLE`) para la gestión centralizada de accesos a la tabla de pacientes y su asignación a usuarios específicos.

## 2. Decisiones en las que participé
- Definición de los perfiles de usuario simulados en la base de datos de turnos médicos (rol administrativo, rol de consulta limitada y rol personalizado de pacientes).
- Aplicación del principio de *mínimo privilegio*, restringiendo el acceso directo de escritura sobre las tablas transaccionales y forzando el uso de procedimientos almacenados auditados.

## 3. Problemas o dificultades identificadas
- Asegurar la distinción clara entre los permisos concedidos directamente a nivel de usuario individual frente a los permisos heredados mediante la pertenencia a un rol del DBMS.
- Controlar que las restricciones de seguridad impidan modificaciones directas (`INSERT`/`UPDATE`) sin bloquear la funcionalidad operativa necesaria para el personal autorizado.

## 4. Soluciones o propuestas realizadas
- Implementación de scripts de prueba estructurados para validar de forma independiente el comportamiento de los 4 usuarios creados ante consultas de lectura y restricciones de escritura.
- Validación local en SQL Server de los errores generados por falta de permisos y su correcta resolución mediante procedimientos encapsulados.
